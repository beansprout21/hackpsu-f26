# hackpsu-f26

HackPSU Fall 2026 project. Team: Ben, Ethan.

**Live:** https://hackpsu-f26.vercel.app (Vercel production, deploys from `main`; each PR gets a preview URL)

## Run locally
1. `npm install`
2. `npm run dev` and open http://localhost:3000

## Setup (each teammate)
1. `gh auth login` (GitHub CLI) and clone this repo.
2. Copy `.env.example` to `.env.local` and fill in values.
3. Open Claude Code in the repo root. It reads `CLAUDE.md` automatically.

## Workflow
- `/sync` before every task: see teammate activity and file overlap.
- `/next` to claim your next assigned issue.
- `/ship` to PR, merge, and post a summary on the issue.

Full rules: `CLAUDE.md`.
